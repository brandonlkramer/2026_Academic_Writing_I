# Academic Writing — Class Slides

Slides for a first-year, source-based academic writing course (Kwansei Gakuin University, School of Education).

Open `index.html` to choose a class. Each class has its own page (`week-NN.html`); add `#5` to the address to open slide 5.

## How this site is made

The pages are generated from Markdown slide decks (Obsidian Advanced Slides format) by `build_class_slides.py`. Do not edit the HTML by hand: edit the deck and rebuild. Speaker notes are removed, and slides marked `<!-- private -->` (for example, slides with real student writing) are left out.

## Hosting

Works as a static site on GitHub Pages: Settings → Pages → deploy from the main branch, root folder.
